# 日期与角色日程

## 从项目文件同步世界书

角色卡配置位于 `src/世界书.yaml`，世界书条目文件位于 `src/世界书/`。在项目根目录运行 `pnpm watch` 后，同步工具会监听这些文件并将更改同步到配置中指定的酒馆角色卡。变量结构脚本只负责注册结构，不再额外覆盖世界书条目。直接在酒馆修改后，如要保留到本地，应先停止监听并通过同步工具提取，避免被本地内容覆盖。

条目名称、顺序和触发设置由 `src/世界书.yaml` 管理。修改初始化文件只影响后续初始化或缺失字段的补全，不会重置已有聊天状态。

游戏采用公历月份、闰年和星期规则。新聊天的起始年月日、累计天数及精力值在「[initvar]变量初始化勿开.yaml」中配置；星期由年月日自动计算，无需填写。部分日期或不合法的日期需要手动修正。

在角色绑定的主要世界书中，在「角色索引」中编辑各角色的 `配置.日程`。没有日程的角色保留原位置。

```yaml
蕾拉妮:
  配置:
    日程:
      随机地点: [雷格努姆学院, 图书馆, 湖岸边]
      每周:
        星期一: 图书馆
        星期二: 随机
      指定日期:
        '0001-01-06': 随机
```

指定日期优先于每周日程；星期和日期都未配置时保留角色当前地点。地点名称应与地图一致。每周或指定日期填写 `随机` 时，从该角色详情的 `随机地点` 列表等概率抽取；列表可以由每个角色独立配置。列表为空时保留原地点并记录提示，不从区域自动选取。

新聊天在初始日按角色详情日程初始化地点；之后点击「休息至次日」时按新日期更新。每个角色每次应用日程时独立抽取一次，实际地点保存在地点名单中，当天读取或切换地点不会重新抽取。

每天的刷新只推进日期和累计天数、恢复精力值、将玩家移回家中，以及按日程更新角色地点。当前没有刷新事件或委托；未来可通过年月日、星期和角色地点添加事件条件。

玩家地点、精力值、游戏时间和攻略角色地点由界面控制；AI 可按变量更新规则提出好感度变更，恋人及表白标记由界面决定。角色配置与基本信息放在角色索引中，背景和性格等扩展设定放在各自的角色扩展详情中；动态状态保存在 MVU 楼层变量。

玩家位置存放在 `player.area.region` 和 `player.area.place`。角色位置集中存放在 `locations.<地点名>.present` 数组中，移动时先从其他地点移除该角色，再加入目标地点；位置未知的角色不出现在任何地点。玩家移动使用 `RPG游戏界面/功能/区域.ts` 中的地点映射同步区域名称；添加地点时应同步维护该映射。
