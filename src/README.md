# 源码目录说明

- `世界书.yaml`：维尔斯特角色卡的同步配置，包含世界书条目的顺序和触发设置。
- `世界书/`：角色卡的世界书条目，初始变量、更新规则、角色索引和角色详情在这里编辑。
- 新增或整理角色详情时，以 `世界书/爱丽丝角色详情.yaml` 的条目结构为准；角色的状态与好感度阶段表现保存在各自的配置中。
- `事件脚本/`：剧情事件逻辑及相关预览。
- `变量结构/`：MVU 变量结构与注册入口。
- `RPG游戏界面/`：游戏界面与功能逻辑。
- `开发工具/旧角色卡/`：原测试卡生成工具和测试；生成工具会向配置的外部素材目录写入文件。

在项目根目录运行 `pnpm watch`，让编写模板和角色卡同步工具监听修改。同步工具依据根目录的 `tavern_sync.yaml` 工作，需要酒馆中启用同步客户端并成功连接。初始值的更改用于新聊天初始化或补全缺失字段，不会重置已有聊天。

世界书通过提示词模板在生成时读取 MVU `stat_data`，地点表和角色状态仅展示当前地点相关部分。需启用提示词模板扩展及其“生成时执行 EJS”开关，并保持角色索引和角色详情条目启用；现有聊天的实际状态不会因修改初始值自动重置。角色详情按当前地点的在场名单输出。
