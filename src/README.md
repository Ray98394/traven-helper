# 源码目录说明

- `世界书.yaml`：维尔斯特角色卡的同步配置，包含世界书条目的顺序和触发设置。
- `世界书/`：角色卡的世界书条目，初始变量、更新规则、角色索引和角色详情在这里编辑。
- 新增或整理角色时，在 `世界书/角色列表.yaml` 的角色索引内编辑基本信息和配置；背景、性格与语言等扩展详情保存在各自的角色扩展详情条目中。
- `事件脚本/`：剧情事件逻辑及相关预览。
- `变量结构/`：MVU 变量结构与注册入口。
- `RPG游戏界面/`：游戏界面与功能逻辑。
- `开发工具/旧角色卡/`：原测试卡生成工具和测试；生成工具会向配置的外部素材目录写入文件。

在项目根目录运行 `pnpm watch`，让编写模板和角色卡同步工具监听修改。同步工具依据根目录的 `tavern_sync.yaml` 工作，需要酒馆中启用同步客户端并成功连接。初始值的更改用于新聊天初始化或补全缺失字段，不会重置已有聊天。

世界书通过提示词模板在生成时读取 MVU `stat_data`，地点表和角色状态仅展示当前地点相关部分。需启用提示词模板扩展及其“生成时执行 EJS”开关，并保持角色索引和角色扩展详情条目启用；现有聊天的实际状态不会因修改初始值自动重置。角色索引只输出在场角色的基本信息；扩展详情由关键词触发，并按当前地点的在场名单输出。

地点条目统一以 `[地点]` 开头：各 `世界书/地点-地点名.yaml` 保存对应地点描述，界面根据当前位置触发对应条目。角色索引及角色扩展条目以 `[角色]` 开头。地图坐标与区域映射仍分别维护在 `RPG游戏界面/状态侧栏.vue` 和 `RPG游戏界面/功能/区域.ts`；新增地点时须一并更新。

训练场当前采用 AI 文字结算：进入训练场后点击游戏消息框上方的“开始战斗”，战斗中通过聊天选择普通攻击、防御或结束回合；普通聊天不再触发开战。战况由 AI 写在战斗回复中，变量继续保存状态。普通攻击命中后另掷 1d20 决定效果倍率，再以 1d4 为基础伤害计算，防御时临时护甲增加 2，人偶生命为 14。玩家护甲为初始护甲（默认 10）加装备护甲加值（默认 0）；装备系统尚未开放，暂不自动更改装备加值。切磋结束恢复玩家战前生命。法术、队友参战等仍是设计稿，尚未接入本次训练战斗；旧设计稿中程序负责战斗结算的安排已由 AI 结算取代。真实酒馆中的骰子展开、变量更新和切磋结束恢复仍需实测。
