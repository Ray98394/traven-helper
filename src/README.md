# 源码目录说明

这里分为通用游戏界面和场景角色卡两部分。素材和可直接导入酒馆的角色卡仍放在 `D:/MyWorkSpace/数据集/酒馆/01`。

```text
src/
├─ RPG游戏界面/                 酒馆助手脚本；保留此入口目录以兼容现有实时监听地址
│  ├─ index.ts                 脚本入口，挂载和卸载界面
│  ├─ App.vue                  界面布局、交互与样式
│  ├─ 功能/
│  │  ├─ 世界书角色列表.ts     读取和校验角色及立绘目录
│  │  ├─ 多角色对话.ts         解析角色、表情和旁白标记
│  │  ├─ 立绘出场.ts           根据最近两条模型回复计算立绘状态
│  │  ├─ 好感度.ts             好感度数据读写与保护
│  │  ├─ 消息过滤.ts           隐藏变量更新和分析等非剧情内容
│  │  └─ 群聊发言顺序.ts       酒馆群聊的角色发言选择
│  ├─ 测试/                    界面功能测试
│  └─ 说明/                    玩法和配置说明
└─ 角色卡/
   ├─ schema.ts                MVU 变量结构
   ├─ schema.json              构建工具生成的 JSON Schema
   ├─ 世界书/                  角色列表、变量初始值与更新规则
   ├─ 脚本/变量结构/index.ts   向 MVU 注册变量结构
   ├─ 工具/                    测试卡打包工具
   └─ 测试/                    变量结构与好感度测试
```

`世界书/双角色初始变量.yaml` 是当前场景测试卡的初始值。

运行现有检查：

```powershell
node 'src/RPG游戏界面/测试/多角色对话.test.mjs'
node 'src/RPG游戏界面/测试/立绘出场.test.mjs'
node 'src/RPG游戏界面/测试/世界书角色列表.test.mjs'
node 'src/场景角色卡/测试/变量与好感度.test.mjs'
```

打包工具会写入 `数据集/酒馆/01` 并覆盖相同名称的生成文件；使用前确认是否需要保留已有文件。世界书角色列表测试卡使用 `工具/生成场景测试卡.py`。
