# 场景记忆

记忆保存在当前聊天变量 `rpgSceneMemories`，不写入角色世界书。每个聊天独立，删除聊天时随聊天删除；没有导出功能。

玩家通过界面切换地点时，将离开地点的未归档正文排入队列，调用当前 API 生成玩家和在场角色各自知道的简短经历。休息只有在玩家实际返回不同地点时触发同样的流程；原地休息不会归档。摘要请求会增加 API 等待与费用。

生成失败或结果无效时保留待处理记录与原文，下次切换地点重试。每次正式请求按当前地点和在场角色注入相关记忆；对已成功归档且来源未被修改的历史，只在提示词与源消息逐字匹配时移除正文，无法确认的消息继续保留。原始聊天消息不会被修改或隐藏。

消息被删除、编辑、切换消息页或回退导致来源变化时，相关摘要不会加载，原文不会被过滤；分支聊天复制的记忆同样只有来源仍匹配时才会使用。已有场景记忆按场景逐条累积，暂未实现长期记忆合并或手动编辑界面。
