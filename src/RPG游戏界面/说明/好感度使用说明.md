# RPG 游戏界面：好感度

本功能读取当前聊天最新消息的 MVU 变量 `stat_data.攻略角色.<角色名>`，角色字段为 `好感度`、`是否恋人`、`表白已触发`、`拒绝后固定`。界面按场景角色卡的 Zod Schema 校验普通数字与布尔值。测试卡初始值为蕾拉妮 45、艾琳 25。

1. 启用 RPG 游戏界面脚本和当前角色使用的 MVU 框架、Zod 变量结构及角色卡世界书。具体步骤见 `D:/MyWorkSpace/数据集/酒馆/01/世界书角色列表使用说明.md`。新建聊天使变量初始化。
2. 界面上方点击“♡ 好感度”查看角色数值和阶段，多个可攻略角色可在面板中切换。未检测到 MVU 或变量时会显示对应提示。
3. 打开“测试工具”，设置 0～100 并点击“应用数值”。手动设置会解除拒绝后的固定，但不会重置表白或恋人状态。要重复测试表白，先点击“重置表白与恋人状态”，再将数值设为 100；此操作会清除当前角色的表白与恋人状态。
4. 未处理表白的角色达到 100 时，界面出现表白选择。接受写入恋人及已触发状态，保持 100；婉拒写入已触发和拒绝后固定，并将好感度设为 99。界面脚本在启用时保护上述状态不被 AI 更新改写，玩家的测试操作可手动调整。

数值改变由 MVU 与角色世界书中的更新规则驱动，普通聊天不是由界面自行评分。表白文字目前为蕾拉妮和艾琳提供专属文案，其他角色暂用通用提示。选择结果写入消息变量，不会自动发送一条玩家聊天消息；需保证角色卡的变量列表条目让模型在后续生成时读取当前状态。

测试注意：本界面使用消息楼层变量，重新生成或回退聊天可能恢复对应楼层的旧状态。不要同时在多个窗口修改同一聊天；按钮每次重新读取最新楼层并写回。MVU 框架及该聊天的变量结构仍需自行配置。本项目的实时监听需有编译监听进程运行；仅在酒馆中勾选“允许监听”不等于监听进程已启动。
