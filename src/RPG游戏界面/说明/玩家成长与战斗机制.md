下面是一份**第一版战斗与玩家成长策划案**。它以当前游戏的学院生活为基础：玩家通过学习纹章魔法、参与日常活动和推进角色关系成长；战斗先从小规模、可控的回合制切磋开始。

本案是设计稿，尚未写入游戏。数值为第一版测试值，后续需要根据实际体验调整。

---

## 一、第一版目标

第一版先实现一条完整的游玩路线：

```text
前往雷格努姆学院
    ↓
学习纹章魔法
    ↓
提高纹章魔法熟练度
    ↓
学习新的纹章法术
    ↓
前往训练场切磋
    ↓
在战斗中使用已学法术
    ↓
结算战斗结果并恢复日常状态
```

同时，玩家可以与蕾拉妮建立合作关系，解锁与纹章学习相关的活动。

第一版的范围控制为：

| 系统     | 第一版内容                                   |
| -------- | -------------------------------------------- |
| 基础属性 | 敏捷、体质、智力                             |
| 魔法类别 | 四类熟练度保留；先开放**纹章魔法**课程与法术 |
| 战斗场景 | 训练场切磋                                   |
| 战斗规模 | 玩家单人或玩家与蕾拉妮，对抗一名训练魔像     |
| 战斗方式 | 回合制、文字与按钮操作                       |
| 角色合作 | 先设计蕾拉妮的合作活动                       |
| 战斗结果 | 结算胜负、资源与文字记录                     |
| AI 作用  | 根据程序给出的结果描写，不负责掷骰和数值结算 |

结晶、爆裂和奥秘魔法继续保留在属性中，第一版不开放课程和法术；它们显示为“暂未开放”。

# 二、玩家基础属性

## 2.1 三维属性

玩家初始三维均为 10。

| 属性     | 主要作用                             |
| -------- | ------------------------------------ |
| **敏捷** | 影响先攻和普通攻击命中               |
| **体质** | 影响生命上限和部分抵抗检定           |
| **智力** | 影响魔力上限、魔法命中和部分法术效果 |

属性修正值采用之前确定的公式：

```text
属性修正值 = 向下取整((属性值 - 10) ÷ 2)
```

| 属性值 | 修正值 |
| -----: | -----: |
|   8～9 |     -1 |
| 10～11 |      0 |
| 12～13 |     +1 |
| 14～15 |     +2 |
| 16～17 |     +3 |
| 18～19 |     +4 |
|     20 |     +5 |

属性允许范围为 **1～20**。

## 2.2 玩家等级

角色等级继续影响生命和魔力上限。第一版没有必要马上做完整的经验升级体系，可以先让玩家保持 **1 级**，以免同时引入太多成长路径。

后续开放升级时，再增加经验、委托奖励和升级条件。

## 2.3 生命值

沿用此前确定的算法：

```text
生命上限 = 10 + 体质修正值
         + (等级 - 1) × max(1, 6 + 体质修正值)

最终生命上限最低为 1。
```

例如：

```text
等级：1
体质：10
体质修正值：0

生命上限 = 10 + 0 = 10
```

## 2.4 魔力值

沿用此前确定的算法：

```text
魔力上限 = max(1, 10 + 智力修正值 × 2 + (等级 - 1) × 3)
```

例如：

```text
等级：1
智力：12
智力修正值：+1

魔力上限 = 10 + 1 × 2 = 12
```

## 2.5 精力值

```text
每日精力上限：4
```

- 移动地点：消耗 1 精力。
- 上课和训练：按活动说明消耗精力。
- 战斗回合本身不消耗每日精力。
- 休息至次日时，精力恢复至 4 点。
- 精力不受体质修正值影响。

生命和魔力在第一版中也于**休息至次日时恢复至上限**。

# 三、玩家属性成长

玩家主要通过**日常活动**提升基础属性，而不是依靠战斗升级时自由加点。

## 3.1 属性成长进度

每项属性有独立成长进度：

```text
敏捷：10，成长进度 0/10
体质：10，成长进度 0/10
智力：10，成长进度 0/10
```

达到要求后，该属性增加 1 点；多余进度保留。

暂定公式：

```text
升级所需进度 = 10 + (当前属性 - 10) × 2
```

第一版从 10 开始成长。若将来允许初始值低于 10，所需进度最低按 10 计算。

| 当前属性 | 升高 1 点所需进度 |
| -------: | ----------------: |
|       10 |                10 |
|       11 |                12 |
|       12 |                14 |
|       13 |                16 |
|       14 |                18 |
|       15 |                20 |

属性达到 20 后不再增长。

## 3.2 成长活动

| 地点   | 活动       |   消耗 | 效果            |
| ------ | ---------- | -----: | --------------- |
| 训练场 | 灵巧练习   | 1 精力 | 敏捷成长进度 +4 |
| 训练场 | 耐力练习   | 1 精力 | 体质成长进度 +4 |
| 图书馆 | 阅读与研究 | 1 精力 | 智力成长进度 +4 |

限制：

- 每种属性成长活动**每天最多一次**。
- 每天最多进行 **2 次属性成长活动**。
- 玩家主动选择活动才会结算。
- 增长由程序处理，不由 AI 根据聊天自由修改。

### 示例

```text
玩家在图书馆进行阅读与研究。

智力成长 +4
智力进度：8/10 → 12/10

智力提升：10 → 11
剩余进度：2/12
```

智力从 10 提升到 11 时，智力修正值仍为 0，因此魔力上限不会改变；提升至 12 时，修正值从 0 提高到 +1，魔力上限随之提高。

## 3.3 属性变化后的资源上限

属性变化后，程序立即重新计算资源上限：

- 上限提高：当前值增加相同差额，保留已损失的数值。
- 上限降低：当前值不超过新的上限。
- 精力上限不随属性变化。

例如：

```text
智力：11 → 12
魔力上限：10 → 12

若提升前魔力为 7/10，
提升后变为 9/12。
```

# 四、魔法熟练度成长

四类魔法熟练度互相独立：

```text
结晶魔法：0级
爆裂魔法：0级
奥秘魔法：0级
纹章魔法：0级
```

第一版只开放**纹章魔法**。

## 4.1 熟练度等级

| 熟练度 | 称号   | 升至下一级所需进度 |
| -----: | ------ | -----------------: |
|      0 | 未学习 |                  4 |
|      1 | 菜鸟   |                  8 |
|      2 | 入门   |                 12 |
|      3 | 熟练   |                 16 |
|      4 | 精通   |                 20 |
|      5 | 大师   |           已达上限 |

普通课程每次获得 **4 点进度**。多余进度保留。

## 4.2 上课规则

玩家位于雷格努姆学院时，可以点击：

```text
[参加纹章魔法课程]

消耗：1 精力
效果：纹章魔法熟练度进度 +4
限制：每天一次
```

完成后显示：

```text
玩家参加了雷格努姆学院的基础课程。

纹章魔法熟练度进度 +4
纹章魔法：0级 → 1级
```

课程由程序结算，不自动生成 AI 回复。玩家之后继续聊天时，聊天记录和每日总结可以为剧情提供依据。

### 每日活动上限

第一版统一设置：

```text
每天最多进行 2 次成长活动。
```

以下活动共享这个上限：

- 属性训练与阅读。
- 魔法熟练度课程。
- 学习具体法术。
- 明确标注为成长活动的角色合作练习。

每个具体活动还受各自的每日次数限制。例如参加一次纹章课程后，当天不能再次选择同一课程，但可以去图书馆阅读。

# 五、纹章法术学习

## 5.1 学习规则

熟练度达到要求后，玩家需要前往雷格努姆学院单独学习法术。

```text
学习法术：
消耗 1 精力
占用当天 1 次成长活动
同一具体法术只能学习一次
```

已学习的法术永久保留；后续可以通过技能菜单查看。

第一版建议先开放 **1～3 级熟练度法术**，4～5 级暂不配置法术。

## 5.2 法术类别

| 类别         | 作用                             |
| ------------ | -------------------------------- |
| **攻击魔法** | 对敌方造成伤害                   |
| **辅助魔法** | 提供护盾、协助队友或改变战斗条件 |
| **技能魔法** | 用于探索、操作物品和场景互动     |

法术中的伤害、消耗和持续时间是第一版测试值。

---

# 六、第一版纹章魔法目录

## 6.1 初学法术：熟练度 1

### 银刃纹章

```text
类型：攻击
学习要求：纹章魔法熟练度 1
消耗：2 魔力
目标：一名敌人
```

展开小型纹章，向目标发射一道魔力刃。

```text
命中后伤害：1d6 + 智力修正值
最低伤害：1
```

这是玩家的基础单体攻击法术。

### 守护纹章

```text
类型：辅助
学习要求：纹章魔法熟练度 1
消耗：2 魔力
目标：自己或一名同伴
```

为目标施加一道守护纹章：

```text
抵消下一次受到的最多 5 点伤害。
触发后消失；未触发时持续至战斗结束。
```

同一目标已有守护纹章时，再次施放会替换旧效果，不叠加。

### 牵引纹章

```text
类型：技能
学习要求：纹章魔法熟练度 1
消耗：1 魔力
使用场景：探索
```

牵动物品或操作简单机关。

可以：

- 拿取视线范围内的轻小物品。
- 拉动未上锁、阻力较小的把手。
- 拉近一张没有固定的纸条。

不能：

- 操纵人物或生物。
- 隔墙取物。
- 强行打开上锁的门。
- 拿取沉重物品。

第一版“轻小物品”暂定为**不超过 1 千克**。

---

## 6.2 进阶法术：熟练度 2

### 双刃纹章

```text
类型：攻击
学习要求：纹章魔法熟练度 2
消耗：3 魔力
目标：一名敌人
```

向同一目标发射两道魔力刃：

```text
分别进行两次命中检定。
每次命中造成 1d4 点伤害。
```

这项法术**不额外加智力修正伤害**，但两次命中检定仍使用智力修正值和纹章熟练加值。

设计目的：伤害更稳定，但消耗高于银刃纹章。

### 共鸣纹章

```text
类型：辅助
学习要求：纹章魔法熟练度 2
消耗：2 魔力
目标：一名同伴
持续：目标下一次攻击结束，或战斗结束
```

在同伴身上留下共鸣纹章：

```text
目标下一次攻击的命中检定 +2。
攻击结算后纹章消失。
```

同一角色不能同时持有多个共鸣纹章；重复施放只刷新效果。

### 留痕纹章

```text
类型：技能
学习要求：纹章魔法熟练度 2
消耗：1 魔力
目标：一件玩家能接触到的物品
```

在物品上留下不显眼的魔法标记。

- 标记保留到休息至次日。
- 第一版同时最多保留 1 个标记。
- 玩家位于同一地点时，可以通过纹章感知该物品的大致方向。
- 无法跨地点实时追踪，也不能透过标记听见或看见周围情况。

---

## 6.3 熟练法术：熟练度 3

### 交错银刃

```text
类型：攻击
学习要求：纹章魔法熟练度 3
消耗：4 魔力
目标：最多两名敌人
```

对选定目标分别发射一道魔力刃：

```text
每个目标分别进行一次命中检定。
每次命中造成 1d6 点伤害。
```

只能选择一名目标时，只造成一次伤害；不能把两道刃都指定给同一个目标。

### 纹章屏障

```text
类型：辅助
学习要求：纹章魔法熟练度 3
消耗：4 魔力
目标：自己或一名同伴
```

为目标提供可承受多次攻击的屏障：

```text
吸收最多 8 点伤害。
护盾耗尽或战斗结束后消失。
```

**同一目标的护盾不叠加**。如果已有护盾，玩家选择保留旧护盾或替换为新屏障。

### 纹章解构

```text
类型：技能
学习要求：纹章魔法熟练度 3
消耗：2 魔力
目标：一处可观察的纹章或法印
```

分析目标的基础结构，可能了解：

- 纹章是否仍在运作。
- 纹章的大致用途。
- 是否存在明显的触发条件。

它**不直接解除纹章**，也不保证识破所有隐藏术式。需要检定时，使用智力修正值与纹章熟练加值；具体难度由事件配置。

# 七、纹章熟练度的战斗作用

熟练度除了决定能否学习法术，还提供较小的命中加值：

| 纹章熟练度 | 纹章法术命中加值 |
| ---------: | ---------------: |
|          0 |               +0 |
|       1～2 |               +1 |
|       3～4 |               +2 |
|          5 |               +3 |

```text
纹章法术命中 = 1d20 + 智力修正值 + 纹章熟练加值
```

熟练度为 0 时不能施放纹章法术；达到 1 级后，仍需要先学会具体法术。

# 八、第一版战斗结构

## 8.1 战斗场景

先开放训练场的**训练魔像切磋**：

```text
地点：训练场
战斗类型：切磋
敌人：训练魔像 ×1
失败后果：切磋结束，玩家不会死亡
```

进入方式：

```text
[开始魔像切磋]
```

第一版暂定切磋**不消耗每日精力**，但战斗中消耗的魔力不会自动恢复。这样玩家可以多次练习，仍需要管理魔力与休息。

## 8.2 训练魔像

```text
名称：训练魔像
等级：1
生命：14/14
魔力：0/0
敏捷：10
体质：12
智力：6

防御值：10
普通攻击命中加值：+0
普通攻击伤害：1d4
```

它不使用魔法，不会逃跑或投降。

**魔像的三维和魔力值属于战斗单位配置草案**，实现时可根据实际平衡调整。

# 九、战斗回合

## 9.1 行动顺序

战斗开始时，各单位掷一次先攻：

```text
先攻 = 1d20 + 敏捷修正值
```

从高到低依次行动；战斗中保持同一顺序。

同分时：

1. 敏捷修正值较高者先行动。
2. 仍相同则由程序随机决定。

## 9.2 每个单位的回合

第一版不使用格子地图：

```text
每回合：
- 1 次主要行动
```

主要行动可选择：

| 行动         | 效果                              |
| ------------ | --------------------------------- |
| **攻击魔法** | 选择已学会的攻击法术              |
| **辅助魔法** | 选择已学会的辅助法术              |
| **普通攻击** | 不消耗魔力                        |
| **防御**     | 直到自己的下一回合开始，防御值 +2 |
| **结束回合** | 不执行主要行动                    |

第一版先不处理自由移动、地形距离和道具。牵引纹章等探索法术只在非战斗场景使用；战斗地图设计完成后，再加入走位和范围规则。

## 9.3 命中与防御

```text
魔法命中 = 1d20 + 智力修正值 + 对应魔法熟练加值

普通攻击命中 = 1d20 + 敏捷修正值

玩家护甲 = 初始护甲 + 装备护甲加值
训练人偶护甲 = 10
```

命中结果大于或等于目标防御值时命中。

第一版暂定：

- 骰子自然掷出 **20**：自动命中，但不额外增加伤害。
- 骰子自然掷出 **1**：自动失手。
- 其他情况按公式比较。

当前普通攻击命中后另掷 1d20 决定效果：1 大失败 ×0.3，2～5 勉强命中 ×0.8，6～15 有效命中 ×1，16～19 暴击 ×1.5，20 大成功 ×2。基础伤害乘效果倍率后向下取整，最低为 0；失手不掷效果骰或伤害骰。法术尚未接入训练战斗，其效果判定另待实现时确定。

## 9.4 普通攻击

```text
消耗：无
目标：一名敌人
伤害：1d4
```

不额外加属性伤害。以后加入武器时再按武器调整。

## 9.5 魔力不足

程序在施法前检查：

1. 是否已经学会法术。
2. 当前魔力是否足够。
3. 目标是否有效。
4. 当前状态是否允许施法。

检查未通过时，不消耗行动和魔力，玩家可以重新选择。

检查通过并正式施法后，**即使命中失败也消耗魔力**。

# 十、战斗状态与结束

## 10.1 生命归零

第一版学院切磋中：

```text
生命降至 0 → 失去本场战斗行动能力
```

- 玩家生命归零：切磋失败。
- 训练魔像生命归零：切磋胜利。
- 有队友参战时，一方全部失去行动能力后战斗结束。

切磋不导致死亡。

## 10.2 状态结束时机

| 状态     | 结束条件                     |
| -------- | ---------------------------- |
| 守护纹章 | 抵消一次伤害后，或战斗结束   |
| 共鸣纹章 | 下一次攻击结算后，或战斗结束 |
| 纹章屏障 | 护盾耗尽后，或战斗结束       |
| 防御     | 防御者下一回合开始时         |

战斗结束后清除所有标明“战斗结束时消失”的效果。

## 10.3 切磋结束后的资源

第一版训练场切磋结束后：

- 玩家与队友生命恢复至**进入切磋时的生命值**。
- 魔力保留实际消耗。
- 战斗状态清除。
- 不自动推进日期。
- 不自动发放经验。

例如：

```text
切磋前：生命 8/10，魔力 10/10
切磋结束：生命 0/10，魔力 4/10
离开切磋：生命恢复至 8/10，魔力保持 4/10
```

正式野外战斗的伤势与失败后果以后另行设计。

# 十一、蕾拉妮的合作成长

蕾拉妮目前已配置基础战斗属性，但**还没有学会任何法术**。第一版需要为她单独配置已学法术，不能因为她是雷格努姆学院学员，就默认她拥有所有纹章法术。

建议测试配置：

```text
蕾拉妮
纹章魔法熟练度：1级
已学法术：银刃纹章、守护纹章
```

她的具体三维与长期战斗定位仍可后续再调整。

## 11.1 合作能力

第一版只做一项：

```text
能力：纹章基础指导

条件：
- 玩家已认识蕾拉妮
- 蕾拉妮好感度达到 30
- 她位于雷格努姆学院或训练场
- 当前角色状态允许互动

活动消耗：
- 1 精力
- 当日 1 次成长活动

获得效果：
- 解锁「纹章基础指导」
```

```text
纹章基础指导：
每天第一次参加纹章魔法课程时，
额外获得 1 点纹章熟练度成长进度。
```

这里的奖励是**进度 +1**，不是熟练度等级 +1。

达到条件只解锁邀请选项；玩家需要主动选择，角色在场才会发生共同练习。完成后，玩家学到的练习方法可以独立使用，不要求蕾拉妮之后一直在场。

## 11.2 是否参加战斗

蕾拉妮是否参加本场切磋，由玩家在战前选择：

```text
训练场切磋

[单人参加]
[邀请蕾拉妮参加]
```

第二个选项要求她在训练场、状态允许且玩家已认识她。她参加后，**由玩家控制她的战斗行动**。

好感度不会直接改变她的命中率或伤害，恋人状态也不是使用合作能力的必要条件。

# 十三、程序与 AI 的职责

## 程序负责

- 检查是否能够进入战斗。
- 保存参战者、行动顺序和当前回合。
- 检查法术是否学会、资源是否足够、目标是否合法。
- 掷骰并计算命中、伤害与状态。
- 扣除魔力，更新生命与护盾。
- 结束战斗并保存结果。
- 处理课程、属性进度和合作能力。

## AI 负责

- 根据已经确定的结果描写动作、场景和角色反应。
- 不自行增加行动次数。
- 不修改骰点、伤害、生命、魔力或已学法术。
- 不替玩家选择下一步行动。

例如程序生成：

```text
玩家使用银刃纹章攻击训练魔像。
命中，造成 5 点伤害。
玩家魔力：10→8。
魔像生命：14→9。
```

AI 只根据这个结果描写，不重新结算。

第一版建议**战斗过程中不自动调用 AI**，直接显示程序生成的简短战斗记录；战斗结束后可以提供一个可选的“生成战斗描述”按钮。这样可以控制等待时间和模型调用次数。

# 十五、建议开发顺序

1. **纹章熟练度课程**：进入学院、上课、消耗精力、增长进度。
2. **法术学习与查看**：先接入 1 级的银刃纹章、守护纹章和牵引纹章。
3. **单人切磋**：玩家对训练魔像，完成先攻、命中、伤害和结束结算。
4. **辅助状态**：接入守护纹章与防御。
5. **蕾拉妮参战**：玩家选择是否邀请，并控制她的回合。
6. **合作成长**：加入纹章基础指导。
7. **扩展法术**：再加入 2～3 级纹章法术和探索技能。

这样第一版可以先验证“**学习 → 施法 → 战斗 → 结算**”是否有趣，再扩展其他三类魔法、正式敌人和复杂战场。
