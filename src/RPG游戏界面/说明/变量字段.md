# MVU 变量字段

游戏状态的字段使用简短英文名；角色名、地点名、状态值和界面文字仍使用中文。新聊天直接使用英文变量，不自动迁移旧聊天的中文字段。

| 原字段 | 英文字段 |
| --- | --- |
| 游戏时间 | `time` |
| 天数 / 年 / 月 / 日 | `day` / `year` / `month` / `date` |
| 玩家 | `player` |
| 护甲 / 初始护甲 / 装备加值 | `armor` / `base` / `equipment`；新聊天初始护甲为 3，总护甲为初始护甲与装备加值之和 |
| 区域 / 名称 / 地点 | `area` / `region` / `place` |
| 精力值 / 当前 / 上限 | `energy` / `current` / `max` |
| 战斗队伍 | `party` |
| 地点表 / 在场角色 | `locations` / `present` |
| 服装指定 | `outfits` |
| 角色状态 / current state / 来源 | `states` / `state` / `source` |
| 攻略角色 / 是否认识 / 好感度 / 好感度阶段 / 表白已触发 | `characters` / `known` / `affection` / `stage` / `confessed` |
| 委托 / 状态 / 进度 / 目标进度 | `quests` / `status` / `progress` / `goal` |
| _角色地点已初始化 | `_locationsInit` |
